# سيناريو فيديو (Odoo Lab) - Odoo Auditor 19  (حوالي 8 دقايق)

**0:00 - مقدمة (20 ث):** "النهارده هنشوف مديول بيراجع سجلاتك لوحده: يطلّع التكرارات، الخصومات العالية، المخزون السالب، وتعارض الصلاحيات."
**0:20 - التثبيت والإعداد (60 ث):** تثبيت المديول، إضافة مجموعة Audit Manager، فتح Quick Setup، ضبط الحدود، Apply.
**1:20 - أول تشغيل (60 ث):** Run Audit، تفعيل Run in background، متابعة شريط التقدم.
**2:20 - الداشبورد (45 ث):** الكروت والأعمدة، الضغط على Critical للوصول للقايمة. (جرّب الوضع المظلم.)
**3:05 - الملاحظات (120 ث):** Kanban، فتح ملاحظة، المستند المصدر، الدليل (Snapshot + SHA-256)، Triage > Investigate.
**5:05 - الإجراء التصحيحي (60 ث):** Create Corrective Action، تعيين مسؤول وموعد، فصل المهام (صاحب الإجراء مينفعش يتحقق منه).
**6:05 - Ignore in Future (40 ث):** رفض مع سبب وإضافة استثناء.
**6:45 - التقارير والتصدير (45 ث):** Export to Excel، تقرير PDF للملخص والخطة.
**7:30 - الأمان (20 ث):** المديول للقراءة فقط، ملاحظات HR سرية.
**7:50 - ختام:** رابط المديول والاشتراك في القناة.

**لقطات مطلوب تصويرها بعد التثبيت (للـ Apps Store):** الداشبورد (فاتح ومظلم)، Kanban الملاحظات، فورم ملاحظة مع الدليل، Quick Setup، شاشة تقدم التشغيل، شاشة Access Review.
