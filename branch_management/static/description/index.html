Inter-branch transfers with approval

Move goods between branches with a clear paper trail. Stock leaves the source warehouse, sits in a transit location and lands in the destination warehouse only when the receiving team validates it.

  • Source availability is checked before any picking is created.
  • Destination users are notified and the destination manager gets a To-Do activity.

  • Cancellation needs a reason and cancels the open pickings. A printable transfer report is included.

Configuration guide

Five steps from installation to the first branch order.

  1. Prepare the building blocks. For each branch, make sure you have a warehouse, and optionally a sales journal, a purchase journal, cash/bank journals and an analytic account.
  2. Create the branches. Go to Branches > Branches and create one record per branch (see the field reference below). The code is generated automatically.
  3. Assign users. Open a user, go to the Branch Access tab, pick the Default Branch and the Allowed Branches, or set the Access Mode to All Branches. Tick Branch Manager for head-office staff.
  4. Optional: restrict journals, contacts and products. Set the Branch field on a journal to reserve it for one branch. Use the Branches field on contacts and products to limit where they can be selected.
  5. Optional: set credit limits. Enter a Credit Limit on each branch and on key customers, or tick Unlimited Credit.

Frequently asked questions

Is this the same as multi-company? No. It keeps one company, one chart of accounts and one set of contacts, while separating operations by branch. Can a user work in several branches? Yes. Add several Allowed Branches and choose the branch on each document. The Default Branch is only a starting point. Can I send stock to a branch I cannot access? Yes. Any user can select any branch as the destination of a transfer, without gaining access to that branch's other data. What happens to documents created before installation? Sales and purchase orders require a branch, so assign branches to existing open documents as part of your rollout. Test on a copy of your database first. Does it work with my custom modules? Branch records are standard Odoo fields and record rules, so custom models can reuse them. Contact support for integration help.
